PatientEvoPhysio v2.0.0
WINDOWS COMMAND REFERENCE
================================

DEPENDENCY INSTALLATION ON A FRESH PC
-------------------------------------
Run once before opening the library in OMEdit:
    INSTALL_DEPENDENCIES_WINDOWS.bat

This installs/verifies Modelica 3.2.3, Complex 3.2.3, ModelicaServices 3.2.3
and Physiolibrary 2.3.1 through the OpenModelica Package Manager, then checks
that PatientEvoPhysio.mo loads successfully. Restart OMEdit afterwards.

RECOMMENDED ONE-CLICK WORKFLOW
------------------------------
Standard validation:
    RUN_STANDARD_VALIDATION.bat

Extended oxygen/transition validation (after standard passes):
    RUN_EXTENDED_VALIDATION.bat

OpenModelica and Python are auto-detected; normal installations do not require
manual PATH edits.

DEFAULT DATA MODE: CURATED
--------------------------
The generator now keeps the scientific subset from config/core_variables.json.

    python scripts\generate_csv.py --scenario neonate_healthy
    python scripts\generate_csv.py --profile hemodynamic_smoke
    python scripts\generate_csv.py --profile neonate_oxygen_10min

FULL RAW OUTPUT (debug/audit only):
    python scripts\generate_csv.py --scenario neonate_healthy --raw

RAW + CURATED:
    python scripts\generate_csv.py --scenario neonate_healthy --both

LIST SCENARIOS/PROFILES:
    python scripts\generate_csv.py --list

INITIALIZATION DIAGNOSTIC
-------------------------
One-click:
    RUN_INITIALIZATION_DIAGNOSTIC.bat

Command line:
    python scripts\diagnose_initialization.py --scenario neonate_healthy

Results:
    data\diagnostics\initialization\neonate_healthy\initialization_summary.json
    data\diagnostics\initialization\neonate_healthy\initialization.log

VALIDATE A RESULT
-----------------
    python scripts\validate_results.py "data\generated\neonate_healthy\neonate_healthy_res.csv"

Outputs:
    neonate_healthy_res.validation.json
    neonate_healthy_res.validation.details.json

VIRTUAL PATIENT PARAMETER SETS
------------------------------
    python scripts\generate_population.py config\virtual_population.example.csv

Optional raw output:
    python scripts\generate_population.py config\virtual_population.example.csv --raw

CLEAN BUILD ARTIFACTS
---------------------
    CLEAN_BUILD.bat

Notes:
- build\ contains disposable compiler artifacts and is ignored by Git.
- data\generated\ contains simulation products and is ignored by Git.
- data\diagnostics\ contains generated diagnostic evidence and is ignored by Git.
- metadata/validation JSON uses portable repository-relative paths when possible.

----------------------------------------
