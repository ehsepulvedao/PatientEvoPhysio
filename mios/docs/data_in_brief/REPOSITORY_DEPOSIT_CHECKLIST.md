# Repository deposit checklist

- [ ] Final curated dataset generated from a tagged software version.
- [ ] Optional raw data retained or explicitly documented.
- [ ] Dataset index generated.
- [ ] Variable dictionary generated.
- [ ] Per-run metadata present.
- [ ] Per-run validation summaries present.
- [ ] Scientific summaries/figures present.
- [ ] Dataset-level quality report passes or every REVIEW item is explained.
- [ ] SHA-256 checksums generated.
- [ ] Parameter-space file and random seed included for virtual cohorts.
- [ ] Dataset README states clearly that data are synthetic/in silico.
- [ ] License selected and documented.
- [ ] Public repository provides a persistent identifier/DOI.
- [ ] Final DOI inserted into manuscript and Data Availability statement.
- [ ] Journal scope confirmed for simulation/synthetic data before submission.
- [ ] Current Data in Brief template/Guide for Authors checked at submission time.
