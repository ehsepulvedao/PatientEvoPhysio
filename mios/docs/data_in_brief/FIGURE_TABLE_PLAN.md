# Suggested data-article figures and tables

These are descriptive data/quality items, not hypothesis-testing figures.

## Figures

1. Dataset generation workflow: parameter/scenario definition → Modelica simulation → curated CSV → validation → scientific summaries → dataset release.
2. Representative neonatal hemodynamic traces: left-ventricular pressure, systemic arterial pressure and valve states.
3. Representative left-ventricular pressure-volume trajectory.
4. Representative arterial oxygen-saturation trajectory for the long neonatal profile.
5. Dataset composition by scenario/profile (generated after final cohort size is fixed).

## Tables

1. Specifications table required by the target data article template.
2. Dataset inventory by profile and scenario (generated from `dataset_index.csv`).
3. Core variable dictionary with units and descriptions.
4. Quality-control summary: simulations, PASS/REVIEW counts, model hash and software versions.
5. Virtual-population parameter ranges and sources, if a sampled cohort is included.
