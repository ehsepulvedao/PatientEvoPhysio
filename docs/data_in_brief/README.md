# Data in Brief preparation folder

This folder contains manuscript and dataset-preparation material for a possible Data in Brief submission.

**Scope caution:** Elsevier's June 2024 Data in Brief quick guide states that datasets in the journal should result from experiment or observation rather than computer simulations. At the same time, Data in Brief has published simulation and synthetic-data articles, including recent examples. Therefore, eligibility of a purely mechanistic in-silico PatientEvoPhysio dataset should be confirmed with the journal/editor before submission. Do not treat this repository as a guarantee of journal scope.

Before submission:

1. generate and quality-control the final dataset;
2. deposit all described data in a public repository with a persistent identifier;
3. insert the final dataset DOI and URL in the manuscript and data-availability statement;
4. confirm journal scope and use the current official template/Guide for Authors;
5. remove all placeholders and internal instructions.

Official materials consulted when this repository was prepared include Elsevier's June 2024 "How to write a good Data in Brief article" quick guide and Data in Brief repository policy.
