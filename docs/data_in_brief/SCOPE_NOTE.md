# Scope note: simulated data and Data in Brief

Elsevier's June 2024 Data in Brief quick guide states that datasets reported in the journal should result from experiment or observation rather than computer simulations. However, Data in Brief has also published articles containing numerical simulation data and, more recently, fully synthetic datasets.

Because these signals are not perfectly aligned, a PatientEvoPhysio data article should not be submitted on the assumption that a purely simulated dataset is automatically in scope. Confirm eligibility with the journal/editor before submission and re-check the current Guide for Authors.

This repository therefore prepares the dataset and manuscript materials in a journal-agnostic, reusable form. If Data in Brief is not appropriate at submission time, the same release package can support another data journal or a repository-first data publication.
